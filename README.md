# RPG Game — Python OOP Project

Welcome to my **RPG (Role-Playing Game) project**, built using **Python and Object-Oriented Programming (OOP)**.

This project is being developed step-by-step as I continue learning and improving my Python programming skills.

## Part 1 — Character & Battle System

This is the **first part of the project**. In this version, the basic RPG structure and battle system have been created.

### Current Features

* Character selection

  * Warrior
  * Mage
  * Assassin
* Different character statistics

  * HP
  * Attack
  * Defence
  * Weapon
  * Potions
  * Coins
* Random enemy generation

  * Goblin
  * Skeleton
  * Orc
  * Dragon
* Player actions

  * Attack
  * Defend
  * Use Potion
  * Run
* Enemy actions

  * Attack
  * Defend
  * Use Potion
  * Run
* Basic damage calculation based on Attack and Defence
* Different stats for each character and enemy
